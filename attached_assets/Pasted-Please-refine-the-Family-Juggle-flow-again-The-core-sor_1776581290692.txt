1. After sorting, the app does not land directly on the final results page. Instead, it returns to the Family screen and shows a “Week sorted / see how it was sorted” status card. The user then has to tap again to view the actual sorted plan.
2. Once sorted, the Family screen has lost the natural ability to keep adding more activities easily.
3. The final results page has drifted away from the Sortii style/colour system, especially in the top dashboard/summary area.
4. On the final results page, the section order feels wrong. “The plan” should come before “Who’s doing the running”.

  1. Input screen

1. Top dashboard / summary
2. The plan
3. Who’s doing the running

Users want the solved overview first, then the individual breakdowns.

Please restyle the results page so it feels consistent with the rest of Sortii:
