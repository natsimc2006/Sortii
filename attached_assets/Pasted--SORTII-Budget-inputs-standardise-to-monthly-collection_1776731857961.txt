## SORTII — Budget inputs: standardise to monthly collection

This is a focused pass on the budget setup screen (MoneySetup / 
BudgetSetup or equivalent) and the calculation logic that feeds from it.
Do not change any other screens.

---

### PART 1 — Frequency label component

Create a reusable FrequencyPill component for use on all budget input 
fields. It renders a small rounded pill to the right of the input field 
showing the collection frequency.

Two variants:

WEEKLY pill:
- Background: #E6F3F0
- Text colour: #2A8F88
- Text: "/ week"
- Font size: 12px
- Font weight: 600
- Border radius: 20px
- Padding: 3px 10px

MONTHLY pill:
- Background: #F6E6BA
- Text colour: #8A6010
- Text: "/ month"
- Font size: 12px
- Font weight: 600
- Border radius: 20px
- Padding: 3px 10px

Replace all existing plain "/ week" and "/ month" text labels on input 
fields with this component. The pill sits inside the input field on the 
right side, replacing whatever frequency indicator is there currently.

---

### PART 2 — Income field: add frequency selector

The income field currently collects a weekly figure. Replace the static 
"/ week" label with a three-option frequency selector:

Options: "Weekly" | "Fortnightly" | "Monthly"
Default: "Fortnightly" (most common AU pay cycle)

Selector style:
- Three small pill buttons in a row, right-aligned inside or directly 
  below the income input field
- Selected pill: teal background (#2A8F88), white text, 12px, 600 weight
- Unselected pill: white background, #E6E1D7 border, #999999 text

Conversion logic (convert to monthly figure for all calculations):
- If Weekly selected: multiply entered value × 4.3
- If Fortnightly selected: multiply entered value × 2.15
- If Monthly selected: use entered value as-is

Store the converted monthly figure as monthlyIncome in state.
Never show the conversion to the user — just use it silently in 
all calculations.

### PART 4 — Calculation logic

All internal calculations must work in weekly figures.
Convert inputs using these rules before any calculation runs:

monthlyToWeekly(value) = value / 4.3

Apply to these fields:
- Mortgage or rent: divide by 4.3
- Bills, loans & regular payments: divide by 4.3
- Streaming & subscriptions: divide by 4.3
- Entertainment: divide by 4.3

Keep these as-is (already weekly):
- Groceries
- Coffee & café
- Takeaway

Income: use the conversion from Part 2 selector, then divide by 4.3 
to get weeklyIncome.

Committed breathing room (weekly):
committedBreathingRoom = weeklyIncome
  - monthlyToWeekly(mortgageRent)
  - monthlyToWeekly(billsLoans)
  - monthlyToWeekly(subscriptions)
  - groceries

Final breathing room (weekly):
finalBreathingRoom = committedBreathingRoom
  - coffee
  - takeaway
  - monthlyToWeekly(entertainment)

Safety rules:
- Treat any empty or null input as 0
- Never render $NaN, $null, or $undefined anywhere
- If finalBreathingRoom === 0 exactly, show $0 — this is valid
- If negative, show as "−$[X] over" in red (#B86557)

### PART 5 — Result cards: add monthly equivalent line

On both result cards (committed breathing room and final breathing room),
add a small monthly equivalent line below the main weekly figure.

Format:
- Main figure: "$[X] this week" — large, teal (#2A8F88)
- Below in small grey text (12px, #999999, italic):
  "~$[Y]/month" where Y = weekly figure × 4.3, rounded to nearest $5

Example:
$87 breathing room this week
~$375/month

Do not show the monthly line if the result is negative.
