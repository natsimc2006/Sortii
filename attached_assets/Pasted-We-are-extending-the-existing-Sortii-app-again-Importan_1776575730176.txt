We are extending the existing Sortii app again.

Important:
Do not rebuild the app.
Do not remove or break existing logic in Meals, Juggle, Appointments or Bills.
This task is to add a new cross-module layer that makes the app feel more like one helpful system.

We are adding:
1. A combined “What’s coming up” screen
2. Gentle reminder logic
3. Optional “assigned to me / assigned to partner / assigned to child” views
4. Weekly glance summary cards with calm, human summary copy

Sortii principles must remain:
- calm
- clear
- low mental load
- supportive
- slightly cheeky in small doses only
- never stressful
- never over-designed
- never like a corporate dashboard
- never like project management software

Use the existing Sortii styling system:
- soft white / warm white background
- soft cards
- clean hierarchy
- gentle accent colour use
- same voice and spacing rules as the existing modules

--------------------------------------------------
PART 1: “WHAT’S COMING UP” SCREEN
--------------------------------------------------

Create a new top-level screen or dashboard section called:

“What’s Coming Up”

Goal:
Give the user one simple, glanceable place to see the next few days across all modules:
- Meals
- Juggle
- Appointments
- Bills

This should feel like relief, not another wall of information.

The screen should:
- combine items from all modules into one unified timeline / grouped view
- show only relevant upcoming items
- prioritise near-term items
- group clearly by time buckets

Suggested time buckets:
- Today
- Tomorrow
- This week
- Later

Each item in the combined view should show:
- module type
- title
- date / time if relevant
- assigned person if relevant
- key support text if relevant
- status chip if relevant

Examples:
- Meal: “Chicken tray bake” — Tonight
- Juggle: “Soccer pickup” — 4:30 PM — For: Max
- Appointment: “Dentist” — Tuesday 3:30 PM — For: Ella
- Bill: “Electricity” — Due Thursday — $142

Add a small module icon or chip per item:
- Meals
- Juggle
- Appointments
- Bills

But keep it clean and understated.

What’s Coming Up top summary panel:
Include a simple top card with calm human copy generated from the upcoming week.
Examples:
- “A few moving parts this week, but nothing wildly offensive.”
- “Thursday’s doing a bit much.”
- “A fairly decent run at the moment.”
- “You’ve got a couple of things creeping up.”

This summary should be generated from simple logic, not random.

Suggested logic examples:
- If 1–3 items total in next 7 days: “A fairly light week by the looks.”
- If 4–7 items: “A few moving parts, but manageable.”
- If 8+ items: “This week’s got a bit on.”
- If one day has significantly more items than others: call out that day
- If there are overdue bills or multiple prep-needed items: mention that gently

Do not use robotic phrasing.
Do not use panic tone.

Also include quick summary chips:
- Meals left this week
- Appointments upcoming
- Bills due soon
- Juggle items left

- a CTA to open full “What’s Coming Up”

Example main lines:
- “Thursday’s doing a bit much.”
- “A few moving parts this week.”
- “Surprisingly civilised so far.”
- “You’ve got a couple of things lining up.”

Example supporting chips:
- 2 appointments
- 1 bill due
- 3 juggle items
- 4 meals left

Logic ideas:
- if one day has 3+ items across modules, mention the day
- if overdue bills exist, mention that gently
- if there are multiple items needing prep, mention that
- if the week is light, say so

Examples:
- “Thursday’s doing a bit much.” / chips: 2 appointments, 1 pickup, 1 bill due
- “A fairly light run this week.” / chips: 1 appointment, 3 meals planned
- “A couple of things need your attention.” / chips: 1 overdue bill, 1 prep item

Do not make this card too large.
It should feel glanceable.

PART 6: UX / PRESENTATION RULES
--------------------------------------------------

Important UX rules:
- Keep the combined view clean and scannable
- Do not dump raw data from four modules into one messy list
- Use date grouping and spacing carefully
- Use plain-English labels
- Avoid icon-only controls
- Keep primary CTAs visible and never blocked by sticky nav
- Completed items should not dominate
- Use subtle colour chips for source type and status
- Use human-readable dates and times only
- Never show raw time logic like minute counts from midnight

Examples of good microcopy:
- “One less thing to keep in your head.”
- “A few things on the radar.”
- “This one’s edging closer.”
- “Tomorrow’s got a couple of moving parts.”

Examples of bad tone:
- “Urgent”
- “Critical”
- “You are behind”
- “Action required immediately”
