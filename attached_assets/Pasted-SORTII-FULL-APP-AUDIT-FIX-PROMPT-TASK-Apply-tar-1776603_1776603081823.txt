PROBLEM: Money is buried inside Meals.

nav presence. Users miss it entirely.

NEW STRUCTURE:
Home | Meals | Add(+) | Family | Money

Replace "More" tab with "Money" tab.
Move all "More" tab content (Preferences,
What's Coming Up, Appointments, Bills,
Saved meal plans) into the Home screen's
settings access OR into a settings icon
in the top-right of the Home screen header.

Icon: dollar sign or wallet icon
Label: "Money"

(matches the Money card colour on Home)

directly — the same screen currently
accessible from within Meals.

── SETTINGS ACCESS (replaces More tab) ───

Add a small settings/gear icon to the
top-right of the Home screen header,
next to "Help me sort this" button.

Tapping it opens a bottom sheet:
Header: "Your setup"

Rows:
[⚙] Preferences
    Household, dietary, seasonal
    → opens Preferences screen

[💰] Money setup
    Budget, savings goal, breathing room
    → opens Money setup

[📋] What's Coming Up
    Everything across all modules
    → opens timeline view

[📅] Appointments
    Doctors, school, anything in the diary
    → opens Appointments

[🧾] Bills
    Track what's coming up and what's paid
    → opens Bills

    Plans you've kept for later
    → opens Saved plans

This bottom sheet replaces the More tab.
Keep it clean — no section headers needed,
just a simple list with icons and chevrons.

── "WHAT'S COMING UP" CARD ───────────────

This card currently duplicates what the
other cards already show.

Replace it with a smarter version:
Only show "What's Coming Up" when there
is a cross-module event worth flagging
— e.g. a family event AND a doctor's
appointment on the same day, or a big
bill due on the same week as a heavy
grocery spend.

Hide this card. Let the individual
cards speak for themselves.

be a genuine cross-module insight, e.g.:
"Busy Saturday — football AND a
doctor's appointment. Juggle sorted ✓"

── HOME SCREEN CARD ORDER ────────────────

Correct order (after cleanup):
1. Greeting + status line
2. Tonight's Dinner (always first —
   most immediate decision removed)

5. Week at a Glance
6. What's Coming Up (only if cross-
   module insight exists)

FIX 4 — MEALS TAB FILTER HIERARCHY
════════════════════════════════════════════

The filter/preference area is currently:
- 3 filter chips in a row (people, budget,
  cost range)
- "Adjust plan" button
- Swap savings banner
- Pantry tip

This is too much happening in one area.
Simplify the hierarchy:

── NEW FILTER BAR ────────────────────────

Replace the 3 filter chips + Adjust button
with a single compact row:

[👥 4 people]  [Budget]  [⚙ Adjust]

3 items only. The cost range ($103–$121)
moves to inside the Adjust sheet —
it's a result, not a filter control.

"Adjust" pill on the right opens the
existing Adjust plan sheet.

── DIETARY INDICATOR ─────────────────────

If a household dietary profile exists
(from the dietary setup feature):

Show a small quiet pill below the
filter bar:
"🌱 Vegan plan" or "🌾 Gluten-free"
or "✓ Kid-friendly lean"

Color: var(--plum-tint) background,
var(--plum) text, 11px, pill shape.

This is the only place the dietary
profile is made visible. Tapping it
opens Preferences → Household profile.

If no dietary profile set:
Show a very subtle prompt instead:
"Dietary needs? Set them once →"
var(--text-muted) 12px underlined link.
Tapping opens dietary setup.

── SWAP BANNER ───────────────────────────

The "Review swaps → save up to $30"
banner is working well. Keep it.
Move it below the filter bar and dietary
indicator, above the meal list.

── SHOPPING LIST TIP ─────────────────────

Add this one-time tip below the
swap banner, above the meal list:

┌─────────────────────────────────────┐
│ 🛒 Your shopping list is ready.     │
│ All ingredients are already in it   │
│ — add anything extra you need.      │
│ [Open shopping list]    [Got it ×]  │
└─────────────────────────────────────┘

Style:
background: var(--teal-tint) #E6F3F0
border: 1px solid rgba(42,143,136,0.2)
border-radius: 12px
padding: 12px 16px
font-size: 13px

"Open shopping list" → teal link,
opens the Shopping list directly.

"Got it ×" dismisses the tip permanently.
Store dismissed state in localStorage:
Key: 'sortii_shopping_tip_dismissed'

Show this tip:
- Only on first 3 visits to Meals tab
- Only if a meal plan exists
- Never again after dismissed

This is the moment users realise the
shopping list is auto-populated —
don't bury it, surface it once clearly.

FIX 6 — FAMILY RESULTS VISUAL UPGRADE
════════════════════════════════════════════

The "HEADS UP" conflict card and
"WORTH KNOWING" card need to land
harder visually. They contain the most
intelligent output in the app but
look like afterthoughts.

── HEADS UP CARD (was ONE THING TO TWEAK)

Current: faint red-pink card, standard text.
Problem: the important info (the conflict
and the recommendation) doesn't have
enough visual hierarchy.

UPGRADE:

Card background: white
Left border: 4px var(--impossible) #B86557
Border radius: 14px
Shadow: 0 2px 12px rgba(184,101,87,0.12)

Internal layout:
┌──────────────────────────────────────┐
│ ⚠ HEADS UP                           │
│ [conflict description — bold 15px]   │
│                                      │
│ [recommendation — teal, 14px, italic]│
│                                      │
│ Options:                             │
│ · [option 1]                         │
│ · [option 2]                         │
│                                      │
│ [Who can help? →] if contacts exist  │
└──────────────────────────────────────┘

The recommendation line (currently in
teal in the screenshot) is the right
instinct — keep it in teal, make it
bold, 15px. This is the AI's direct
advice and should read as the most
important line in the card.

── WORTH KNOWING CARD ────────────────────

Current: plum-tinted card, good structure.

UPGRADE:
Add a subtle ✦ sparkle icon before
the label (already present — keep it).
Increase the body text to 15px
(currently feels too small relative
to the card).
Add 4px var(--plum) left border.
Ensure max 3 sentences — if AI returns
more, truncate at third sentence end.

── PER-ADULT SCHEDULE CARDS ─────────────

These (Mum/Dad cards) are the visual
highlight of the results screen.
Small upgrade to make them shine more:

Each adult card:
- Add a coloured dot before the name
  matching their family member colour
  (already present in Family tab —
  use the same colour system)
- "Free from [TIME]" line:
  Change from italic muted text to:
  background: var(--free-tint) #E8F8F0
  color: var(--free) #4AB88A
  border-radius: 20px
  padding: 4px 12px
  font-size: 13px
  font-weight: 500
  Display as a small pill, not plain text.
  This makes the free time feel like a
  reward, not just data.

- "[Adult]'s list →" button:
  Current: border-only teal, full width.
  Change to: full width but with a
  small share icon (✈ or ↗) before
  the text. This signals it's a
  send/share action.

── SUMMARY STAT PILLS AT TOP ─────────────

Current: "4 events · 1 tight spot · 1 sorted ✓"
as pill tags in a row.

These are good but the visual weight
doesn't communicate urgency properly.

Update colours:
"X events" pill: teal tint bg, teal text
"X tight spot" pill: gold tint bg, gold text
"X sorted ✓" pill: green tint bg, green text
"X issues" pill: red tint bg, red text

Each pill: border-radius 20px, 
padding 4px 14px, font-size 13px,

This makes the status instantly readable
