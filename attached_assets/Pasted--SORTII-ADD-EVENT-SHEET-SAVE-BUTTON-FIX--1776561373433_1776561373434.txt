STEP 4 — THE SAVE HANDLER
════════════════════════════════════════════

The handleSaveEvent function must:

1. Build an event object from all
   current form state values:

const newEvent = {
  id: Date.now().toString(),
  title: titleValue,
  day: selectedDay,
  startTime: selectedTime || manualTimeValue,
  endTime: endTimeValue || null,
  location: locationValue || null,
  involvedPeople: selectedPeople || [],
  driver: selectedDriver || null,
  repeat: selectedRepeat || 'one-off',
  notes: notesValue || null,
  createdAt: new Date().toISOString(),
};

2. Add this event to the events array
   in whatever state management or
   storage system the Family tab uses
   (AsyncStorage, Context, useState —
   use whichever is already in place).

3. Close the sheet.

4. Show a brief success toast or
   confirmation on the Family tab:

After sheet closes, show a small toast
notification at the bottom of the screen:

"Event added. ✓"

Toast style:
- Background: #2A8F88 teal
- White text, 14px, bold
- Border radius: 20px
- Padding: 10px 20px
- Centred horizontally
- Appears for 2.5 seconds then fades
- Sits above the bottom navigation bar

5. After saving, if the event has a day
   of Saturday or Sunday, also show the
   "Sort the family juggle →" button on
   the Family tab main screen
   (this button should already exist from
   the previous build — just ensure it
   appears after the first weekend event
   is added).

STEP 5 — FIX THE CLOSE BUTTON BEHAVIOUR
════════════════════════════════════════════

Currently the × button closes the sheet
and discards all entered data silently.

Update the × button behaviour:

IF the form has any data entered:
  Show an inline confirmation:
  "Discard this event?"
  [Yes, discard] [Keep editing]
  
  Both as small text links below the
  header — not a blocking modal.
