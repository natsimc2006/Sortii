I want to rebuild the Family module flow so it is much easier for the user to understand and move through, while keeping all of the smart engine logic underneath.

Important

Do NOT remove or simplify the smart logic layer already built.

Keep and continue using:

* estimated travel time based on suburb/location inputs
* overlap detection
* tight timing / pressure detection
* driver assignment and split logic
* recurring event handling
* “worth knowing” summary generation
* recommendation logic
* best-option / least-painful-plan logic

The goal is NOT to reduce intelligence.
The goal is to make the journey to the untangled output much clearer.

⸻

New product model

The Family module should work as a simple 3-step journey:

Step 1: Add what’s on

User adds:

* family members
* who can drive / help
* events / activities / appointments
* locations, times, repeat settings
* optional tricky notes

Step 2: Untangle it

One strong CTA triggers the smart logic.

Step 3: See the plan

The app reveals the organised output:

* who is doing what
* what works
* what is tight
* what does not fit cleanly
* what Sortii recommends

⸻

1. Separate input state from sorted output state

Right now the Family screen mixes:

* event entry
* partial summaries
* plan outputs
* sort CTA

This is confusing.

Please redesign so that:

Before the user presses the main action

Show only:

* family members entered
* events entered
* a simple raw count / light setup summary
* one strong CTA to run the planner

Do NOT fully surface plan split, “who’s covering what”, conflict recommendations, or final sorted outputs before the user triggers the smart planner.

After the user presses the main action

Reveal the full sorted outputs and planner logic.

⸻

2. Replace the current main CTA with clearer language

Replace “Sort the family juggle” with a clearer, more human primary action.

Preferred CTA text:
“Sort this out”

Alternative acceptable options:

* “Untangle this week”
* “Make this work”

Use one consistent primary label across the module.

This CTA should feel like the hero action of the feature.

Family
