TASK 3 — FIX GO_BACK NAVIGATION ERROR
────────────────────────────────────────
There is a "The action 'GO_BACK' was not handled" error visible 
in the Money setup flow screens (budget input, savings goal).

Find where navigation.goBack() is called in the Money setup 
screens. The likely cause is that these screens are being pushed 
onto a stack that has no previous route to go back to.

Fix: wrap the goBack() call in a safety check:
  if (navigation.canGoBack()) {
    navigation.goBack();
  } else {
    navigation.navigate('Home'); // or the tab name for Home
  }

Apply this fix wherever navigation.goBack() is called in the 
Money setup flow files.
