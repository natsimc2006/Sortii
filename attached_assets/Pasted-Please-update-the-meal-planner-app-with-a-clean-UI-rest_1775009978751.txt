10. MEAL VARIETY IMPROVEMENTS
==================================================

Fix the issue where meals repeat too often when many preferences are selected.

Update the generation logic:
- Do not repeat the exact same meal within the same generated week unless there are not enough valid options left
- Avoid too many meals with the same main protein back-to-back where possible
- Avoid too many meals with the same cuisine type back-to-back where possible

Selection logic should use staged filtering:

Stage 1:
- Filter by hard exclusions only:
- excluded ingredients
- allergens
- strict dietary restrictions

Stage 2:
- Score meals using soft preferences:
- budget level
- max cook time
- cooking style
- health style
- prep style
- leftovers mode
- ingredient overlap / minimise waste mode
- household suitability

Stage 3:
- Rank meals by best fit

Stage 4:
- Build the week from the top-ranked pool while enforcing diversity/no-repeat rules

If the pool becomes too small:
- relax soft preferences slightly before allowing repeats
- hard exclusions must always stay enforced

If fallback repeats are still necessary:
- show a helpful notice:
“Your current preferences are limiting meal variety this week. Try relaxing one or two filters for more options.”
