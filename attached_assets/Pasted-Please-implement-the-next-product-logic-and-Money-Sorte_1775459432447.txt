ENSURE COST DIFFERENTIATION BY TIER

Please make sure the weekly estimated cost changes meaningfully by tier.

Expected pattern:

Super Budget = lowest estimate
Budget = low-mid estimate
Standard = mid estimate
Premium = highest estimate

Do not let Super Budget / Budget / Standard all return almost identical cost ranges unless the actual selected week genuinely overlaps by chance.

If needed, widen tier cost bands so the user can feel the difference.
