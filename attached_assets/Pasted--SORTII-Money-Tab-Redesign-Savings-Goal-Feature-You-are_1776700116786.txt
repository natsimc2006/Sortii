### PART 2: Savings Goal Feature

**New data fields** — add to user profile / AsyncStorage:

savingsGoal: {
  name: string,              // e.g. "Japan" — 20 char max
  targetAmount: number,
  currentSaved: number,      // starts at 0 or user-entered
  weeklyContributions: []    // array of numbers, one per week
}

---

**Setup flow — 3 inputs only**

Add as an optional final step in the budget setup flow.
Also accessible from the Money tab via a quiet text link: "Set a savings goal →"

Screen layout:
- Title: "Saving for something?"
- Subtext: "We'll factor it in."
- Skip link top-right: "Skip →"

Input 1: What are you calling it?
- Free text field, 20 char max
- Placeholder: "e.g. Trip, New car, Buffer"

Input 2: Target amount?
- Numeric field, currency formatted
- Placeholder: $0

Input 3: Already saved anything?
- Numeric field, currency formatted
- Placeholder: $0
- Subtext below: "Leave blank to start from zero."

CTA button: "Set goal →" — gold (#D29A22), full width

---

**Savings logic — calculate these values:**

weeklyDinnerSaving = estimatedEatingOutCost - dinnerPlanCost
remainingToGoal = targetAmount - currentSaved
weeksToGoal = remainingToGoal / weeklyDinnerSaving
progressPercent = (currentSaved / targetAmount) * 100

Each week a new meal plan is confirmed: increment currentSaved by
weeklyDinnerSaving and append to weeklyContributions array.

Safety rules:
- If weeklyDinnerSaving is 0 or negative: do not increment, do not render
  a weekly saving figure
- If targetAmount is 0: suppress the card
- Never render NaN, $0/week, or divide-by-zero results — suppress the
  relevant line instead

---

**Dynamic copy — getSavingsGoalCopy() function**

Return one string based on these conditions, checked in this order:

1. First week set (weeklyContributions.length === 1):
   "Goal set. Keep this up and you'll hit [name] in ~[weeksToGoal] weeks."

2. Milestone reached (progressPercent crosses 25, 50, or 75):
   25%: "You're a quarter of the way to [name]. Keep going."
   50%: "Halfway to [name]. Dinner at home is working."
   75%: "Nearly there. [name] is close."

3. Ahead of schedule (currentSaved > targetAmount *
   (weeklyContributions.length / weeksToGoal)):
   "You're ahead of target. [name] might come sooner than planned."

4. Strong week (weeklyDinnerSaving > average of weeklyContributions * 1.2):
   "Good week. This one covered [X]% of your [name] fund."

5. Light week (weeklyDinnerSaving < average of weeklyContributions * 0.8):
   "Tight week — [name] holds steady. Back on track next week."

6. Default (on track):
   "You're on track for [name]. ~[weeksToGoal] weeks away."

---

**Savings goal card — Money tab component**

Render as a plum tint (#F3E8EE) card. Only render if savingsGoal.name and
savingsGoal.targetAmount are set and valid.

Layout:
- Top row: [emoji if name suggests one, otherwise ✦] [name] fund
  — right side: [progressPercent]% in plum (#5E3A4C)
- Progress bar: gold (#D29A22) fill on grey track, full width
- Second row: "$[currentSaved] of $[targetAmount] saved" — small, grey
- Third row: "This week added ~$[weeklyDinnerSaving]" (teal) |
  "~[weeksToGoal] weeks to go" (grey)
- Dynamic copy line: output of getSavingsGoalCopy() — italic, plum, small
- Bottom text link: "Update goal →"
