─── STEP 2: Create the swap matching utility ───

Create utils/getSwapsForRecipe.ts:

import { SWAP_RULES, SwapRule } from '../constants/swapRules';

export function getSwapsForRecipe(ingredients: string[]): SwapRule[] {
  const ingredientText = ingredients.join(' ').toLowerCase();
  
  return SWAP_RULES.filter(rule =>
    rule.matchKeywords.some(keyword =>
      ingredientText.includes(keyword.toLowerCase())
    )
  );
}

─── STEP 3: Build the Swap Tip UI component ───

Create components/SwapTips.tsx

This component receives a recipe's ingredients array and renders 
swap suggestions if any rules match.

Design:
- Compact card, sits below the recipe card on the planner screen
- Background: #F3E8EE (plum tint) — signals "smart feature"
- Small plum left border accent: #5E3A4C
- Header row: 💡 "Save money on this meal"
- Each matched swap renders as one row:

  [swap icon →] "Swap [original] → [swapLabel]"    "save ~$[X]/serve"

- Maximum 3 swaps shown per recipe (highest saving first)
- If more than 3 match, show "2 more swaps available" in small text
- A small "×" dismiss button top-right to hide tips for that meal slot
  (store dismissed state in local component state, not persisted)

Sortii voice for the tip text — show on tap/press of each row:
  Small expandable tip text using the recipe's tip field
  E.g. "Thighs are juicier anyway."

─── STEP 4: Wire SwapTips into the planner ───

In the weekly planner view, for each filled meal slot:
- Call getSwapsForRecipe() with that recipe's ingredient names
- If 1 or more swaps match, render the SwapTips component 
  below that meal card
- If zero swaps match, render nothing

The swap tips should be:
- Visible but not intrusive — below the card, not overlaid
- Collapsible: show a small plum "💡 Swaps available" pill on 
  the meal card itself that expands/collapses the SwapTips panel
- Default state: collapsed (don't overwhelm on first view)

─── STEP 5: Add total swap saving to the planner header ───

In the weekly plan header/summary area, if any swaps are available 
across the week's meals, show a single line in plum:

  "💡 Apply all swaps → save up to $[X] this week"

Calculate [X] by summing the highest savingPerServeAUD per matched 
swap × householdSize × number of meals that swap applies to.

Round to nearest dollar. Only show if saving is $2 or more.
