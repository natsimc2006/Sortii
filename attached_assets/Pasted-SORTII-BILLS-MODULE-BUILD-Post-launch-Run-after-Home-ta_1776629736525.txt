SORTII — BILLS MODULE BUILD
Post-launch. Run after Home tab is confirmed working.
Do not run this prompt during App Store submission phase.

━━━ CONTEXT ━━━
Sortii is a React Native / Expo app. It already has:
- A Home tab (home.tsx) showing today's dinner + money snapshot
- A Money tab storing weekly income, fixed costs, grocery spend,
  and a calculated weeklyBreathingRoom value
- A Planner tab storing the weekly meal plan in AsyncStorage
- Meal savings tracked as cumulativeSavings or similar

Before writing any code, do the following:
1. Search the Money screen file for the AsyncStorage key used to
   store money data. Log it in a comment at the top of your work.
2. Search the Money screen for how weeklyBreathingRoom is derived
   (stored value or calculated fresh). Log this too.
3. Search the Planner or Money screen for how dinner savings /
   cumulativeSavings is stored. Log the exact key name.
   If no savings tracking exists yet, note this — do not create
   savings logic, just design the Bills module to accept a
   savings value of 0 safely.

Only proceed once you have confirmed all three key names.

━━━ PHASE 1: DATA LAYER ━━━
Create a new utility file: utils/billsService.ts

It must contain:

1. STORAGE KEY
   const BILLS_KEY = '@sortii_bills';

2. BILL TYPE
   export type Bill = {
     id: string;           // uuid
     name: string;
     amount: number;
     dueDate: string;      // ISO 8601 "YYYY-MM-DD"
     recurring: boolean;   // repeats monthly
     canPush: boolean;     // user flagged as deferrable
     paid: boolean;
     paidDate: string | null;
   };

3. FUNCTIONS (all async, all wrapped in try/catch):
   - getAllBills(): Promise
   - saveBill(bill: Bill): Promise
   - updateBill(id: string, updates: Partial): Promise
   - deleteBill(id: string): Promise
   - getBillsDueThisWeek(): Promise
     → returns unpaid bills where daysUntilDue <= 7
   - getTotalDueThisWeek(): Promise
     → sum of amounts for bills due this week (unpaid only)

4. DERIVED HELPER (not stored — calculated at runtime):
   - generateNextRecurringBill(bill: Bill): Bill
     → takes a paid recurring bill, returns a new Bill object
        with dueDate incremented by 1 month and paid: false
     → called automatically when a recurring bill is marked paid

5. SAFETY RULES for all functions:
   - Never return undefined — return [] or 0 as fallback
   - If AsyncStorage read fails, return empty state silently
   - Never mutate the stored array directly — always read,
     clone, modify, write
